# Методика демо

Все значения синтетические. Снимок фиксирован на 23.11.2026, набор начинается 01.09.2026. Повторный запуск даёт те же данные.

## Метрики

| Метрика | Правило |
|---|---|
| Новые лиды | Уникальные ID, созданные в диапазоне |
| Презентации ОКК | Уникальные ID с подтверждённой презентацией |
| ВКС | Уникальные ID лида в объединении двух журналов |
| Оплаченные сделки | Уникальные ID сделок с положительным платежом |
| Поступления | Сумма платежей; рассрочки складываются |
| Расход | Прямые расходы + отдельно учтённая доля общих затрат |
| ДРР | Сумма расходов / сумма поступлений |
| Цена ВКС | Сумма расходов / уникальные лиды с ВКС |

Деньги хранятся в целых копейках. Деление на ноль возвращает «—». Презентации и ВКС не выводятся из стадии CRM.

## Два режима

**Календарь:** этапы и платежи по датам событий выбранного периода; новые лиды по дате создания. Деление календарных ВКС на новые лиды не названо конверсией.

**Когорта:** лиды созданы в выбранном периоде; их этапы и платежи учитываются до даты снимка. Конверсия лид → ВКС — доля лидов этой когорты с хотя бы одной ВКС. Расход в обоих режимах относится к выбранному периоду.

Фильтр менеджера выбирает ответственного за лид. Демо не распределяет расходы по менеджерам; в их таблице нет стоимостных показателей.

## Рекомендации

Подписи в демо — иллюстративные правила для ручного разбора. «Проверить возврат» означает: были поступления, но нет расхода в последние 7 дней снимка. Это не разрешение повторного обзвона и не доказательство прибыли.

Порог ДРР 60% используется только для демонстрации интерфейса и не является согласованным нормативом. Рекомендации учитывают текущий фильтр периода; исторический аудит требует отдельного полного периода. Отсутствие дохода за 60 дней само по себе не основание остановки.

Для настоящего решения дополнительно нужны маржа, зрелость лидов, фактический расход за последние дни, объём выборки, обработка лидов и проверка перезапусков.
