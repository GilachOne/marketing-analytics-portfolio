# Приватность публичной версии

Публичный репозиторий создан с новой историей Git. Производственные выгрузки и старые коммиты не копировались.

- Нет исходных таблиц, файлов .env, токенов, вебхуков, SSH-ключей и адресов рабочих серверов.
- Нет имён клиентов, телефонов, email, сотрудников, реальных названий проектов, баз и рекламных кабинетов.
- Числа генерируются с нуля; это не реальные суммы с заменёнными подписями.
- Скриншоты получены в локальном демо на тех же синтетических данных.
- Нет отправки форм, подключения к CRM или внешним аналитическим трекерам.
- Серверные конфигурации и закрытые исходники не опубликованы.

`npm run check` проверяет текстовые файлы и перечень запрещённых типов. Автоматическая проверка — дополнительный контроль, она не заменяет ручной просмотр, особенно изображений.
